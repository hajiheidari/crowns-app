# Tiaro website (tiaro.espadna.com + espadna.com/tiaro-app/)

Everything Tiaro serves on the web comes from this repo, nothing from other projects:

| Address | What | Source |
|---|---|---|
| https://tiaro.espadna.com | web game (no ads, no purchases), challenge `/c/<code>` and invite `/?r=<ref>` links, `?lang=fa\|en` | Expo web export (`scripts/build-site.mjs`) |
| https://tiaro.espadna.com/privacy, `/privacy-fa`, `/terms`, `/.well-known/*` | legal pages, app/universal-link files | this folder |
| https://espadna.com/tiaro-app/ (`fa/`, `ar/`) | landing page in English, Persian, Arabic | `tiaro-app/`, generated by `scripts/landing-pages.py` |

Hosting: one Cloudflare Worker, `crowns-app` (`wrangler.jsonc`), built by Workers Builds on every push to the
production branch (`claude/android-app-execution-uzwdw8`; deploy command `npx wrangler deploy`, no build command).
`wrangler deploy` runs `scripts/build-site.mjs`; unknown paths get the game's index.html (SPA).

How the addresses reach the Worker (set once in Cloudflare, not in `wrangler.jsonc`):
- `tiaro.espadna.com`: Worker custom domain.
- `espadna.com/tiaro-app*`: Worker **route** on the espadna.com zone. The rest of espadna.com (studio home) is another
  Worker (`espadna-site`, in the pantomime repo); it only lists Tiaro as a product card.

`_redirects` must not point at `/index.html` (Cloudflare rejects it as a loop).
